# GitHub Trending CLI

A command-line interface tool to fetch and display trending GitHub repositories based on a specific time range.

## Prerequisites

- Node.js (v14 or higher)
- npm (Node Package Manager)

## Installation

1. Clone or download this repository.
2. Navigate into the project directory:
   ```bash
   cd github-trending-cli
   ```
